# 🏏 IPL SQL Analysis

## 📌 Project Overview
SQL-based analysis of IPL match data to extract meaningful insights
using MySQL.

## 🛠️ Tools Used
- MySQL
- SQL
- GitHub

## 📊 Dataset
IPL match dataset containing match details, teams, toss results,
venues, winners and Player of the Match.

## 🔍 SQL Concepts Used
- SELECT
- WHERE
- DISTINCT
- ORDER BY
- GROUP BY
- HAVING
- COUNT
- SUM
- AVG
- MAX
- MIN
- CASE
- Subqueries

## 📈 Key Analysis
- Team with the highest number of wins
- Team with the lowest number of wins
- Most frequent Player of the Match
- Toss winner vs match winner
- Matches by season
- Matches by venue
